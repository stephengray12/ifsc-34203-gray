# Arkansas' Fun

This project is setup using vue3, veautify, typescript.

The purpose of this project is to make enjoying arkansas wildlife more convenient. It gives access to weather through geolocation for hunting/fishing/hiking.
Another feature is quick and easy access to licensure, and guidelines in regards to hunting and fishing inside of arkansas.
This started off as a school project, but I may end up actually building this out more, because I see great value in wildlife education, and believe most 
people want to enjoy this beautiful state, but don't know where to start.
